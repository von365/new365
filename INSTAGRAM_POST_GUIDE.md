# Sheikh Muzaffer Ozak Instagram Carousel Guide

## 🎨 Project Overview

This project contains a complete Instagram carousel (7 slides) featuring the wisdom of **Sheikh Muzaffer Ozak** from his seminal work **"Love is the Wine: Talks of a Sufi Master in America"**.

The carousel connects ancient Sufi teachings with modern wellness topics:
- Deep hygiene & spiritual purity
- Circadian rhythms & natural living
- Fresh air sleeping practices  
- Early rising & dawn consciousness
- Healing nervous exhaustion through remembrance

---

## 📁 Files Included

1. **instagram-post.html** - Interactive carousel viewer with download functionality
2. **instagram-captions.md** - Complete caption templates, hashtags, and posting strategy
3. **INSTAGRAM_POST_GUIDE.md** - This file (comprehensive usage guide)

---

## 🚀 How to Use

### Method 1: Download Individual Slides

1. Open `instagram-post.html` in your web browser
2. Scroll through the 7 carousel slides
3. Click "Download Slide X" button under each slide
4. Each slide will be saved as a PNG image (1080x1350px - Instagram carousel format)

### Method 2: Download All Slides at Once

1. Open `instagram-post.html` in your web browser  
2. Scroll to the bottom
3. Click the "Download All Slides as ZIP" button
4. Extract the ZIP file to get all 7 slides

---

## 📱 Posting to Instagram

### Step-by-Step Guide:

1. **Open Instagram** and tap the "+" icon
2. Select **"Post"** → **"Multiple"**
3. Upload all 7 slides in order (slide_1 through slide_7)
4. Add filters if desired (recommend: no filter or subtle warm tone)
5. Tap "Next"
6. **Copy caption** from `instagram-captions.md` (choose your preferred option)
7. Add **location** (optional): Istanbul, Turkey or your local mosque/Islamic center
8. Tag relevant accounts (optional):
   - @thresholdsociety
   - @sufi_way
   - Any Islamic/spiritual wellness accounts
9. **Post!**

### Optimal Posting Times:
- **Thursday 6-8 PM** (evening reflection)
- **Friday 9-11 AM** (pre-Jummah browsing)  
- **Sunday 5-6 AM** (Fajr time for spiritual seekers)

- **Text Primary**: #0a0a0a / #fafafa (light/dark mode)
- **Text Muted**: #737373 / #a8a8a8 (light/dark mode)
- **Text Faint**: #a8a8a8 / #737373 (light/dark mode)
- **Border**: #dbdbdb / #262626 (light/dark mode)
- **Border Soft**: #efefef / #1c1c1c (light/dark mode)
- **Background**: #ffffff / #000000 (light/dark mode)
- **Background Soft**: #fafafa / #121212 (light/dark mode)

### Spiritual Theme Colors
- **Gold Accent**: #d4af37 (used sparingly for title slide ornamentation)
- **Navy Background**: #0f3460, #1a1a2e (title slide only)
- These maintain the Sufi/spiritual aesthetic while the content slides use Instagram's clean white design

### Typography
- **All Text**: Inter (Instagram's official font)
  - Headings: Inter 700 (bold)
  - Body: Inter 400 (regular)
  - Quotes: Inter 400 italic
  - Accents: Inter 600 (semibold)

### Layout Principles
- **1080 x 1350px** per slide (Instagram carousel standard)
- **Clean borders** inspired by Instagram's UI (subtle, minimal)
- **Generous whitespace** for mobile readability
- **Centered alignment** for optimal Instagram viewing
- **High contrast** for accessibility (WCAG AA compliant)
- **Dark mode support** via CSS prefers-color-scheme

## 🛠️ Technical Notes

### Browser Compatibility:
The HTML file works in all modern browsers:
- Chrome/Edge (recommended)
- Firefox  
- Safari
- Mobile browsers

### Dependencies:
The download functionality uses:
- html2canvas.js (screenshot generation)
- JSZip (ZIP file creation)
- FileSaver.js (download triggering)

All libraries loaded from CDN (no installation needed).

### Troubleshooting:

**Images not downloading?**
- Enable pop-ups for the page
- Try different browser
- Check download folder permissions

**Slides look different when downloaded?**
- This is normal - html2canvas renders slightly differently
- Quality is optimized for Instagram (high DPI)

**ZIP download not working?**
- Download slides individually  
- Use desktop browser (not mobile)
